<h2>사용자가 체감하는 성능과 유지보수성을 함께 고민하는 프론트엔드 개발자입니다.</h2>

<ul>
<li>단순히 기능을 구현하는 데 그치지 않고, 서비스 운영 과정에서 발생하는 문제의 원인을 분석하고 구조적으로 개선하는 것을 중요하게 생각합니다.</li>
<li>Scroll 기반 렌더링 성능을 최적화하였습니다. 동시에  공통 비즈니스 로직을 Custom Hook으로 추상화하여 중복 코드를 제거하고 유지보수성을 높였습니다.</li>
<li>Section 기반 Infinite Scroll 구조와 화면 상태 동기화를 설계하여 사용자 경험과 서비스 품질을 함께 개선해왔습니다.</li>
</ul>
